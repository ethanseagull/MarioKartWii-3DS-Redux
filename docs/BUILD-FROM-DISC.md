# Building from your disc

Follow the [README build guide](../README.md#building): after installing the
tools, `tools/build.py` builds the CIA and the SD folder from your own USA
RMCE01 disc image and your 3DS's CFL_Res.dat in one command. It was run from a
fresh disc on 2026-11-01.

To run the stages one at a time instead, see
[manual build operations](MANUAL-BUILD.md), the
[resource-stage reference](MANUAL-RESOURCE-STAGES.md) and
[HOME-BANNER.md](HOME-BANNER.md) for the banner.
